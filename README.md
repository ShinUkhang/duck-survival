# 후더덕 서바이벌 🦆🔫

3D 카툰풍 로그라이크 서바이벌 웹게임. 용감한 오리 히어로가 되어 좀비 오리 무리에게서 살아남아라!

- 🕹️ 이동: WASD / 방향키 / 모바일 조이스틱 (공격은 자동)
- 🔫 무기 6종: 꽥건, 메테오 스트라이크, 번개 체인, 궤도 오리, 프로스트 노바, 포커스드 레이저 (각 5레벨)
- 💎 적을 처치하고 별 젬을 모아 레벨업 → 3장 중 1장 선택
- 👹 90초마다 거대 좀비 거위 보스 출현
- 🌽 옥수수(체력 회복), 🧲 자석(젬 흡수) 픽업
- 🏆 로컬 최고 기록 저장, WebAudio 효과음

## 실행

`index.html`을 브라우저로 열면 바로 실행된다. (단일 파일, 외부 의존성 없음)

## 테스트

- Node 헤드리스 로직 테스트 63/63 PASS
- Chromium 실제 렌더링 확인 (타이틀/플레이/레벨업/게임오버/호드 웨이브)
